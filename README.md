# NYC Housing & Traffic Crashes

Data Engineering and Visualization - Milestone 1 (GIU, Winter 2026)

## Research question

Do ZIP codes that received more affordable housing also see more traffic crashes and injuries?

## Datasets

- Housing: Affordable Housing Production by Building (hg8x-zxpr) - https://data.cityofnewyork.us/d/hg8x-zxpr
- Transportation: Motor Vehicle Collisions - Crashes (h9gi-nx95) - https://data.cityofnewyork.us/d/h9gi-nx95

## Setup

1. Clone the project repository:

   ```bash
   git clone https://github.com/mashalyy12/nyc-housing-crashes.git
   ```

2. Navigate to the project directory:

   ```bash
   cd nyc-housing-crashes
   ```

3. Install the required dependencies:

   ```bash
   py -m pip install -r requirements.txt
   ```

4. Run the dashboard:

   ```bash
   py app.py
   ```

5. Open http://127.0.0.1:8050 in your browser.
